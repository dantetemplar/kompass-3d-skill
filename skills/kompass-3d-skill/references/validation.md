# Проверки, диагностика и JPEG вида

### Проверки по риску, а не по списку

**Обычное решение задачи:** достаточно успешного построения, отсутствия ошибок операций и сравнения объёма с эталоном, если он дан. Не добавлять обход граней/рёбер/вершин, аудит связей размеров, проверку всех габаритов, пробные изменения размеров и повторное открытие файла. Для локальной правки проверить только её результат. Проверять по завершении логического действия, а не после каждого setter.

**Расширенные проверки полезны**, когда есть неизвестный маршрут API, существенно другая геометрия, ошибка/подозрительный результат, смена топологии с зависимостями или требование к посадке/движению. Проверять именно затронутые поверхности, связи или зазор. При известной неоднозначности bool из рецепта читать фактический результат; это не разрешение игнорировать произвольные ошибки. Успешный `Update()` сам по себе не доказывает нужную форму.

**Регрессия рецептов:** подробные `validate` предназначены для разработки и повторной проверки примеров. Расчёт объёма, полный аудит, save/reopen и испытание всего хода обычно избыточны для локальной правки, но могут быть полезны для диагностики или приёмки. Проверку повторного открытия выполнять на собственной копии.

Проверки соразмерять задаче; неизменившиеся части обычно не требуют повторных измерений. Экспорт, рендер и замеры производительности добавлять, когда они нужны для результата. Защита пользовательских документов и безопасность Undo сохраняются независимо от объёма проверок.

#### Минимальное построение и контроль твёрдого тела

Рабочий вариант для плоского профиля: `GetSketchs().Add()` → `SetPlane(part.GetDefaultObject(c3d.o3d_planeXOY))` → `sketch.Update()` → `BeginEdit(False)` → активный вид фрагмента → `ksapi.IDrawingContainer(view)` → геометрия → `EndEdit()` → выдавливание. Круг внутри внешнего замкнутого контура задаёт сквозное отверстие без отдельного выреза.

Выдавливание: `model.GetExtrusions().Add(c3d.o3d_bossExtrusion)` → `SetProfiles([sketch])` → `SetDirection(c3d.dtNormal)` → `SetSideParameters(True, c3d.etBlind, depth, 0.0, False, None)` → `Update()` → `part.RebuildModel(True)`. Здесь `None` использован для ограничителя при заданной глубине; это не универсальное разрешение для произвольного режима.

Контроль: `ksapi.IFeature(extrusion).GetResultBodies()` возвращает список; проверить число тел, `body.IsSolid()` и `body.GetGabarit(0, 0, 0, 0, 0, 0)`. Последний возвращает `(status, xmin, ymin, zmin, xmax, ymax, zmax)`. `extrusion.GetDepth(True)` проверяет параметр глубины, не наличие выреза в теле. `doc.SaveAs(absolute_path)` возвращает статус. Для размеров и толщины простого выдавливания не требуется исследовать массу и инерцию.

В [03_holes.py](../examples/03_holes.py) / [02_ring.py](../examples/02_ring.py) есть `verify_cylindrical_walls`: `ksapi.IFeature(part).GetModelObjects([c3d.o3d_face])` → `ksapi.IFace(obj)` → `IsCylinder()` → `GetRadius()` и `GetLimitingEdges()`. Для круговых рёбер `GetMathCurve().GetGabarit(...)` даёт центр, радиус и уровни Z двух границ стенки. Они сопоставляются с ожидаемыми стенками кольца и отверстий, включая глухую глубину; проверка выполняется до сохранения. Это ограниченный контроль простых цилиндров вдоль Z без скруглений и разбиений. Для выреза из нижнего эскиза XOY в материал Z>0 нужна пара `dtReverse` + `SetSideParameters(False, ...)`; `Update=True` не доказывает наличие отверстий. Итоговое тело проверяется через `IFeature(part)`, не через пустой список результата операции выреза. Готовые самостоятельные примеры и JPEG — в [каталоге рецептов](examples.md#каталог-готовых-примеров).

### JPEG вида документа

Изображение вида — отдельный запрошенный результат, не часть обычного построения ([сохранение](documents.md#сохранение), [§30](documents.md#30-не-повторять-неизменившуюся-работу)). Штатный маршрут: `IKompasDocument.SaveAsToRasterFormat` с `IRasterConvertParameters`. Готовый пример — [17_raster_preview.py](../examples/17_raster_preview.py), краткий рецепт — [§35](#35-сохранить-jpeg-вида).

Перед экспортом: `doc.SetActive()`, выбрать нужную проекцию через `IKompasDocument3D.GetViewProjectionManager()` (для стандартной изометрии — `GetViewProjectonType() == ksVPIsometric`, затем `SetCurrent(True)`), команды кадра `ksCMShadedWireframeMode` и `ksCMZoomEntireDocument` через `GetDocumentFrame().ExecuteKompasCommand`. Параметры: `GetInterface(ksObjectRasterConvertParameters)` → `IRasterConvertParameters` → `Clear()`, `SetRasterFormat(ksRasterFormatJPG)`, `SetColorBPP(24)`, `CalcRasterScale(doc, width, height)` с положительным конечным масштабом.

Путь JPEG — **новый**: ни `SaveAs`, ни `SaveAsToRasterFormat` не имеют per-call overwrite. Существующий файл или symlink не трогать; перед записью повторить проверку отсутствия. Успех — `True` от `SaveAsToRasterFormat`, непустой файл и сигнатура JPEG (`FF D8 FF`). Размер пикселей после `CalcRasterScale` может отличаться от запрошенных width/height — это нормально. Не использовать `SetHideMessage` как обход коллизии путей.

### 9. Проверить и сохранить результат

Для простого выдавливания габариты — как `validate` в [01_plate.py](../examples/01_plate.py); сохранение — `doc.SaveAs` в новый путь ([§9](#9-проверить-и-сохранить-результат)).

Габариты тела читаются через `body.GetGabarit(0,0,0,0,0,0)`. Возврат: `(status, xmin, ymin, zmin, xmax, ymax, zmax)`. Размер по каждой оси — разность максимума и минимума.

Для конечного результата обычно нужен `ksapi.IFeature(part).GetResultBodies()`. Список тел отдельной операции может быть пустым или содержать только новые копии ([§15](features.md#15-повторить-тела-или-операции), [§21](features.md#21-повернуть-и-перенести-тело-внутри-детали)).

`verify_cylindrical_walls(part, expected)` проверяет простые цилиндрические стенки вдоль Z, без скруглений и разбиений. Запись: `(x, y, radius, zmin, zmax)`.

**Сохранение:** `doc.SaveAs(absolute_path)` возвращает статус. Проверьте, что появился непустой файл. `save_new` дополнительно запрещает перезапись существующего файла. Для уже открытого рабочего файла есть `doc.Save()`.

Сохраняйте только принятый результат. Если важно доказать сохранность, откройте проверочную копию и повторите проверки. `SaveAs` не собирает внешние файлы в переносимый комплект. Экспорт и изображения не обязательны после каждой правки ([§30](documents.md#30-не-повторять-неизменившуюся-работу)). JPEG вида — [§35](#35-сохранить-jpeg-вида).

### 25. Проверить ошибки дерева и опору эскиза

Для обычной правки начните с `GetObjectError()` затронутой операции. Полный обход нужен для регрессии, неясной ошибки/сломанных зависимостей или явно запрошенного аудита, а не после каждого изменения. `Update=True`, успешное перестроение и одно тело не означают, что все операции исправны.

Образец обхода — `feature_errors` в [01_plate.py](../examples/01_plate.py): `ksapi.IFeature(obj).GetObjectError()` и рекурсивный `GetSubFeatures(c.ksOperTree, True, True)`. Пропускайте пустые ссылки и уже посещённые `reference`. В ошибке полезны путь элемента, тип, код и состояние.

`GetState()` — набор флагов, не код ошибки: `0x8` — зависимость от ЛСК, `0x100` — недоопределённый эскиз, `0x200` — определённый, `0x2` — нужно перестроение, `0x2000` — фиксация компонента. Ненулевое значение само по себе не ошибка.

Код `GetObjectError()==54` означает «Неизвестная ошибка». У эскиза проверьте опорную плоскость: `sketch.GetPlane()` не должен возвращать `None`. Это одна из возможных причин, не универсальная расшифровка кода 54.

#### Эскизу с собственной системой координат всё равно нужна плоскость

Одного `sketch.SetCoordinateSystem(lcs)` недостаточно. Перед первым обновлением и редактированием:

1. Создайте три точки `origin`, `origin+u`, `origin+v`, где `u/v` — независимые направления плоскости. API: `model.GetPoints3D().Add()`, `SetX/SetY/SetZ`, `Update()`.
2. Создайте плоскость: `aux.GetPlanes3D().Add(c3d.o3d_plane3Points)` → `ksapi.IPlane3DBy3Points(plane)` → `SetPoint1/2/3` → `Update()`.
3. Назначьте эскизу и `SetPlane(plane)`, и `SetCoordinateSystem(lcs)`.

Точки и плоскость можно скрыть, но не удалять. Для спирали с началом на +X касательная равна `(0,R,pitch/(2*pi))`; с ней согласуется нормаль круглого профиля пружины.

Не считайте позднее назначение плоскости готовым ремонтом уже ошибочного эскиза; после правки проверьте его состояние и зависимые операции.

### 33. Выбрать грань или окружность по геометрии

[geometric_selection.py](../examples/geometric_selection.py) — самостоятельный пример: скопировать в макрос только нужные функции, не импортировать скилл как библиотеку. Селекторы не меняют модель и не запускают CAD; запуск примера создаёт и закрывает только свою временную деталь. Нужны `part` и **текущее результирующее тело** `body`; принадлежность объектов телу проверяется через `GetBody()`. После rebuild/Undo/reopen заново получить тело и вызвать селектор, не хранить прежние topology references.

- `select_plane(part, body, point=..., normal=..., length_tol=..., angle_tol=...)`: плоская грань с нормалью, параллельной заданной, и опорной плоскостью через `point`. Сравниваются нормализованные направления и расстояние до плоскости. **Не проверяет попадание точки внутрь обрезанного контура**; несколько копланарных граней — неоднозначность, а не право выбрать первую.
- `select_circle(part, body, center=..., radius=..., normal=..., length_tol=..., angle_tol=...)`: целое круговое ребро по центру, радиусу и нормали плоскости. Дуги и эллипсы исключены. Центр/радиус читаются из `IMathCurve3D`, не вычисляются по bounding box.
- `select_cylinder(part, body, radius=..., axis_point=..., axis=..., span=(t0, t1), length_tol=..., angle_tol=...)`: радиус, направление и положение осевой прямой, затем осевая протяжённость ограниченной грани. `span` задаётся в мм от `axis_point` вдоль нормализованного **заданного** `axis`; при смене знака оси меняются знаки/порядок интервала. Не путать диапазон вдоль оси с мировыми Z.

Начало и ось аналитической поверхности/окружности читаются через `GetPlacement().GetOrigin(...)` и `GetVector(c3d.o3d_axisOZ, ...)`. Нормаль/ось сравниваются **без знака**: `n` и `−n` эквивалентны; это не выбор внешней стороны тела. Координаты должны быть в одной системе детали; размещения вхождений сборки автоматически не применяются.

Допуски **обязательны**: `length_tol` — положительное расстояние в мм для координат/радиусов; `angle_tol` — угловое отклонение в радианах. Значения `1e-5` мм и `1e-7` рад в примере относятся к его аналитической геометрии, а не являются универсальным производственным допуском. Проверяются статусы выходных кортежей, конечность чисел и ненулевые направления; ошибка чтения не маскируется пропуском кандидата.

Ноль или несколько совпадений дают `ValueError` с запросом, количеством совпадений и измеренными признаками кандидатов. Нет выбора по индексу, ближайшему объекту или автоматического расширения допуска. Для уточнения ограничить тело/геометрические признаки под задачу.

**Граница цилиндрического рецепта:** протяжённость читается по полным круговым торцам, перпендикулярным оси, и концам прямых швов. Подходящий по опорному цилиндру кандидат с дуговой/сплайновой или иной неподдерживаемой обрезкой останавливает выбор: нужен отдельный маршрут точного анализа границ, не подмена мировым AABB или выборкой точек. Совпадение опорного цилиндра и осевого диапазона не доказывает полноту стенки, отсутствие разрывов или назначение «отверстие»; это выбор объекта, не общий валидатор топологии.

### 34. Диагностический указатель: симптом → действие

Читать только ветку наблюдаемой ошибки; это не обязательный checklist построения.

- **Грань/ребро недоступны после rebuild, Undo или reopen:** получить текущие тела и повторить геометрический выбор ([§33](#33-выбрать-грань-или-окружность-по-геометрии)). Старый `reference` не постоянный ID; затронутые зависимости — [§28](assemblies.md#28-изменить-существующую-сборку-без-пересоздания), Undo — [раздел Undo](documents.md#undo).
- **Нет совпадения или совпадений несколько:** прочитать признаки кандидатов, проверить тело, систему координат, радиус, осевую прямую и диапазон ([§33](#33-выбрать-грань-или-окружность-по-геометрии)). Уточнить запрос; не брать первый индекс и не увеличивать допуск вслепую.
- **Setter/Update прошёл, но форма прежняя или другая:** проверить фактическую затронутую геометрию и применимость режима. Для глубины проверить сторону операции ([§6](features.md#6-выдавить-профиль-или-сделать-вырез)), для фаски/скругления — объём и соседнюю грань ([§14](features.md#14-сделать-фаску-или-скругление)), для смещения плоскости — нормаль опоры ([§22](features.md#22-не-перепутать-направление-смещения-плоскости)); не подбирать цепочки rebuild и не крутить знак параметра вслепую. `None` у setter не ошибка, `True` не доказательство формы.
- **Вхождения в сборке «лесенкой» / ступенчато:** искать цепочку сопряжений деталь→деталь; перепривязать к общим базам корпуса/рамы и сверить матрицы ([§27](assemblies.md#27-задать-сопряжения-и-ограничить-ход)). Не чинить смещением следующей детали.
- **Вызов оборвался или не завершился, результат неизвестен:** остановить все API-вызовы, включая `finally`-cleanup ([§24](documents.md#24-закрыть-только-свои-временные-документы)); сохранить последний этап/traceback. Без новых CAD-вызовов установить, жив ли прежний процесс, завершился ли макрос и нет ли модального окна. Не запускать второй клиент, автоматический `OpenKompas`, Undo или повтор записи. Только после подтверждения работоспособности разрешена адресная инспекция; при признаках повреждения структуры — ветка ниже. Правила диалогов — [сохранение](documents.md#сохранение).
- **После изменения иерархии оторвались базы mates, появились ошибки дерева или сбой solver/rebuild:** считать сессию подозрительной; не запускать в ней следующие эксперименты, даже если API снова отвечает. Не вызывать глобальный rebuild, вращение/экспорт вида, закрытие и переключение документов ради проверки. Записать PID, версию CAD, этап, пути и уже полученные ошибки; не перезаписывать исправный исходник. Для продолжения нужен контролируемый запуск чистого CAD и проверка последнего известного исправного файла/копии. Сначала согласовать сохранение пользовательских несохранённых данных; не убивать и не перезапускать процесс автоматически. После нового запуска все handles получить заново.
- **Диалог «Перестроить?» после неудачного переноса/удаления объектов:** не нажимать «Да» автоматически. Зафиксировать предшествующий вызов и блокировку; перестроение может вызвать сбой в повреждённой модели. Это не то же самое, что обычный rebuild исправного документа.
- **`Segmentation fault` / core dump:** это сбой нативного процесса, а не исключение Python. Сопоставить время последнего API-этапа с журналом КОМПАС и backtrace core. Предшествующие Qt-предупреждения сами по себе не доказывают причину; пустое окно/низкая загрузка GPU не доказывают сбой GPU.

Если неизвестно имя/маршалинг конкретного метода — адресный `sdk.py inspect`/`page` из раздела [документации и сигнатур API](setup-sdk.md#документация-и-сигнатуры-api), не повторное исследование всех уже известных операций.

### 35. Сохранить JPEG вида

[17_raster_preview.py](../examples/17_raster_preview.py) строит пластину 60 × 40 × 10 и пишет **новый** JPEG текущего вида (изометрия, shaded+wire, zoom all). Запуск: `--output /absolute/path/to/preview.jpg`.

Цепочка `save_view_jpeg(doc, target, width=640, height=480)`:

1. Отклонить существующий `target` / symlink.
2. `doc.SetActive()` → `GetViewProjectionManager()` → единственная `ksVPIsometric` → `SetCurrent(True)`.
3. `GetDocumentFrame()`: `ksCMShadedWireframeMode`, `ksCMZoomEntireDocument`.
4. `IRasterConvertParameters`: `Clear` → `ksRasterFormatJPG` → 24 bpp → `CalcRasterScale(doc, width, height)`.
5. `doc.SaveAsToRasterFormat(path, parameters)`; проверить статус, размер файла и JPEG-magic.

Имя метода проекции в API — `GetViewProjectonType` (опечатка в binding). Подробности и ограничения путей — [JPEG вида документа](#jpeg-вида-документа).
