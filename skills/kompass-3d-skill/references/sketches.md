# Эскизы, геометрия, кривые и 2D

#### Эскиз и геометрия

1. `IPart.GetDefaultObject(objectType)` — получить опорную геометрию; для базовой плоскости найти `o3d_planeXOY`, `o3d_planeXOZ` или `o3d_planeYOZ`.
2. `IModelContainer.GetSketchs()` → `ISketchs`; `ISketchs.Add()` → `ISketch`.
3. `ISketch.SetPlane(plane)`, затем `ISketch.BeginEdit(readOnly)` → `IFragmentDocument`.
4. Проверить у `IFragmentDocument` доступ к видам; получить активный `IView` и запросить `IDrawingContainer`.
5. Получить нужные коллекции и создать контур. Проверить параметры геометрии, `Update()` и замкнутость контура.
6. Завершить `ISketch.EndEdit()` до создания операции. В макросе обеспечить завершение редактирования при исключении через `finally`.

Искать страницы `isketch_beginedit`, `isketch_endedit`, затем методы конкретной геометрии. Для новых плоскостей, проекций и пространственных кривых исследовать отдельные интерфейсы, не подменять их базовыми плоскостями.

#### Кривые: сначала один элемент

Для новой кривой или сомнительного setter сначала построить и проверить **один** элемент (центр, углы, длину, точки на кривой), затем переносить приём на весь контур. Наличие метода в `ICircle`/`IArc`/`IBezier`/`INurbs` не означает нужную семантику параметра; имена из справки сверять с фактическим вызовом.

- `ICircle`: центр через `SetXc`/`SetYc`, не `SetX`/`SetY` — оба набора есть, `exists`/поиск по имени ошибку не поймают.
- `IArc.SetDirection(True)` — по часовой стрелке, `False` — против; углы `SetAngle1/SetAngle2` задаются в градусах. Готовая функция с проверкой длины и внутренней точки — [рецепт 17](#17-построить-дугу-с-нужным-направлением). Универсальное сопряжение с обрезкой и ограничения `ICurve2D.CouplingCurveCurve` — [рецепт 18](#18-соединить-два-участка-касательной-дугой); числовой результат этого метода не является готовыми объектами кривых.
- `drawing.GetBeziers().Add()` → `IBezier`. Для открытой составной кубической кривой: `SetClosed(False)`, затем `AddPoint(index, x, y, x_left, y_left, x_right, y_right)` для каждого узла; `left`/`right` — абсолютные координаты управляющих точек. `AddPoint` возвращает кортеж, проверять его статус. После задания узлов — `Update()`.
- Точность аппроксимации Безье зависит от построения управляющих точек и шага, не от одного факта использования Безье.
- При использовании `INurbs.SetNurbsParams` с полюсами, весами и узлами проверить расстояние до расчётных точек на одном коротком участке до генерации всей модели.
- `obj.GetCurve2D().PointOn(parameter, 0, 0)` возвращает статус и координаты; параметры брать из `GetParamMin()`/`GetParamMax()`. `GetDistanceToPoint(x, y)` измеряет расстояние до фактической кривой. Начать с концов и нескольких внутренних точек представительного участка; увеличить выборку только при необходимости.
- Для повторяющегося профиля считать ошибки аппроксимации локально; в API проверить представление одного участка, стыки и итоговое тело. Выборочная проверка — не доказательство максимальной ошибки между точками. Допуск выбирать из задачи и масштаба геометрии, не ужесточать произвольно до нанометров.

### Размерные зависимости эскиза

Следующие методы доступны в нативном KsAPI; **наличие метода не гарантирует нужный результат для произвольного эскиза**.

- `IDrawingObject.NewConstraint()` → `IParametricConstraint`: до `Create()` задать `SetConstraintType`, `SetPartners([...])` и нужные `SetIndex`/`SetPartnerIndex`; после проверить результат и `IsValid()`. Windows-имя `IParametriticConstraint` и одиночный `Partner` не переносить в нативный KsAPI. Для изменения уже созданной связи документация описывает удаление/создание; post-create `SetConstraintValue()` не считать доказанным resize-маршрутом.
- Геометрические связи: `ksCMergePoints`, `ksCHorizontal`, `ksCVertical`, `ksCParallel`, `ksCPerpendicular`, `ksCEqualLength`, `ksCEqualRadius`, `ksCTangentTwoCurves`, `ksCSymmetryTwoPoints`, `ksCConcentricity`. Фиксировать минимальную базу, не все вершины.
- Линейные размеры: `ISymbols2DContainer(view).GetLineDimensions().Add()`, координаты выносных линий, `SetOrientation(ksLinDHorizontal/ksLinDVertical/ksLinDParallel)`, `Update()`. Связь с геометрией — `ksCAssociation`; управляющие связи — `ksCFixedDim` / `ksCDimWithVariable`. Точный порядок создания и индексы требуют проверки. `Associate()` может выбрать не ту совпадающую точку: проверять фактических партнёров и результат изменения.
- Для изменения существующего управляющего размера эскиза использовать `ksapi.IFeature(sketch).GetVariableByName(False, True, name)` **вне `BeginEdit`** → `IVariable.SetExpression(...)` и `SetValue(...)` (возвращают `None`) → `doc3d.CompleteRebuildDocument()`. Проверять фактическую геометрию, состояние solver и ошибки операций; восстановить номинал. `view.GetDimensionVariable(dim)` внутри временного 2D-фрагмента не даёт воспроизводимого изменения геометрии; успешные `UpdateVariables()` и `fragment.CompleteRebuildDocument()` этого не гарантируют. `UpdateVariables()` относится к внешним переменным, не является универсальной заменой solver.
- `IDimensionText.SetNominalValue()` меняет показанный текст, а не геометрию. Декоративная надпись и fully-constrained фиксация не доказывают размерное управление.

Объекты drawing из завершённого `BeginEdit` не использовать в следующем сеансе; вновь получать через ID в актуальном fragment. Пример: [16_dimension_driven_sketch.py](../examples/16_dimension_driven_sketch.py).

Справка из Windows-кэша объясняет назначение, но её имена и COM return types не определяют маршалинг нативного KsAPI. Например, локальные `Save()` / `SaveAs(path)` возвращают `res`, хотя Windows-страницы описывают void Automation methods. Ни `SaveAs`, ни `SaveAsToRasterFormat(path, parameters)` не имеют локального per-call overwrite/silent-флага. `IApplication.SetHideMessage()` задаёт глобальные автоматические ответы и может затронуть ссылки/перестроение; не использовать его как обход коллизий файлов. Правила новых выходных путей и владения документами — в разделе [сохранения](documents.md#сохранение).

### 3. Создать эскиз на базовой плоскости

Нужны `part` и её `model` из [§2](documents.md#2-подключиться-и-создать-документ). Функция `sketch_xoy` (как в [01_plate.py](../examples/01_plate.py)) создаёт эскиз на XOY, открывает редактирование и обязательно завершает его при выходе из блока.

```python
with sketch_xoy(part, model) as (sketch, drawing):
    rectangle(drawing, -30, -20, 60, 40)

operation = extrude(model, sketch, 10)
```

**Результат:** прямоугольник 60 × 40 мм, выдавленный на 10 мм.

Внутри `sketch_xoy` выполняется последовательность:

1. `model.GetSketchs().Add()` — создать эскиз.
2. `sketch.SetPlane(part.GetDefaultObject(c3d.o3d_planeXOY))` — назначить плоскость.
3. `sketch.Update()`, затем `sketch.BeginEdit(False)` — открыть редактирование.
4. Получить активный вид фрагмента и `ksapi.IDrawingContainer(view)` — доступ к геометрии.
5. В `finally` вызвать `sketch.EndEdit()` — закончить редактирование.

Для XOZ или YOZ замените базовую плоскость и проверьте направление осей. Координаты внутри эскиза не обязательно совпадают с мировыми координатами ([§19](features.md#19-создать-отдельные-тела-объединить-их-или-построить-по-сечениям), [§22](features.md#22-не-перепутать-направление-смещения-плоскости)).

### 4. Нарисовать отрезки и замкнутый контур

Нужен `drawing` открытого эскиза. `rectangle` — как в [01_plate.py](../examples/01_plate.py); отрезок — через `GetLineSegments().Add()` с `SetX1/Y1/X2/Y2`.

```python
points = [(0, 0), (40, 0), (30, 20), (0, 20)]
for start, end in zip(points, points[1:] + points[:1]):
    line(drawing, start, end)
```

Последний отрезок соединяет последнюю точку с первой. Для обычного прямоугольника достаточно `rectangle(drawing, x, y, width, height)`.

Прямые вызовы API:

- Отрезок: `GetLineSegments().Add()`, затем `SetX1/SetY1/SetX2/SetY2` и `Update()`.
- Прямоугольник: `GetRectangles().Add()`, затем `SetX/SetY/SetWidth/SetHeight` и `Update()`.
- Многоугольник одним вызовом — [§19](features.md#19-создать-отдельные-тела-объединить-их-или-построить-по-сечениям).

**Проверьте:** контур замкнут, не пересекает себя и не содержит рёбер нулевой длины. Для сложных контуров можно использовать `shapely.Polygon(points).is_valid` и `.area`.

### 5. Нарисовать окружность и отверстие

В открытом эскизе вызовите:

```python
circle(drawing, 0, 0, 25)  # Наружная окружность, радиус 25 мм.
circle(drawing, 0, 0, 5)   # Внутренняя окружность, радиус 5 мм.
```

После выдавливания получится кольцо. Внутренняя замкнутая окружность задаёт отверстие в профиле.

В API центр окружности задаётся через **`SetXc/SetYc`**, а не `SetX/SetY`: `drawing.GetCircles().Add()` → центр → `SetRadius` → `Update()`.

Для отверстия в уже существующем теле создайте отдельный эскиз и вырез ([§6](features.md#6-выдавить-профиль-или-сделать-вырез)). Окружности не должны касаться друг друга или внешнего контура. Наличие окружности в эскизе ещё не доказывает наличие отверстия в теле — проверьте результат.

### 7. Повторить окружности в одном эскизе

Для нескольких одинаковых отверстий проще нарисовать все окружности в одном эскизе и сделать один вырез.

**По окружности.** Нужны `count` — число отверстий, `pitch_radius` — радиус расположения центров, `hole_radius` — радиус отверстия.

```python
import math

for i in range(count):
    angle = 2 * math.pi * i / count
    circle(drawing, pitch_radius * math.cos(angle), pitch_radius * math.sin(angle), hole_radius)
```

**По сетке.** Нужны число строк/столбцов `rows`, `cols`, начало `x0`, `y0`, шаги `step_x`, `step_y` и `hole_radius`.

```python
for row in range(rows):
    for col in range(cols):
        circle(drawing, x0 + col * step_x, y0 + row * step_y, hole_radius)
```

Выберите один рисунок. Проверьте, что отверстия не пересекаются и не выходят за материал. Для повторения самой операции или отдельных тел используйте [§15](features.md#15-повторить-тела-или-операции).

### 8. Построить гладкую кривую Безье

Функция `bezier(drawing, nodes)` принимает узлы вида `(x, y, x_left, y_left, x_right, y_right)`. Последние четыре числа — **абсолютные координаты** управляющих точек, не смещения от узла.

Если известны функция кривой `p(t)` и её производная `d(t)`, один кубический участок между `t0` и `t1` можно приблизить так:

```python
h = (t1 - t0) / 3
p0, p3 = p(t0), p(t1)
p1 = p0 + h * d(t0)
p2 = p3 - h * d(t1)
```

Здесь `p(t)` и `d(t)` возвращают массивы `numpy`; для кортежей нужны покоординатные вычисления. `p0/p3` — концы, `p1/p2` — управляющие точки.

API: `GetBeziers().Add()` → `SetClosed(False)` → `AddPoint(index, x, y, x_left, y_left, x_right, y_right)` → `Update()`. `AddPoint` возвращает кортеж: проверяйте **первый элемент**, а не истинность всего кортежа.

**Проверьте сначала один участок:** концы, стыки и несколько внутренних точек. Для фактической кривой доступны `GetCurve2D().GetDistanceToPoint(x,y)` и `PointOn(parameter,0,0)`; границы параметра — `GetParamMin/Max`. Выборка точек не доказывает точность между ними. NURBS из другой библиотеки нельзя переносить без проверки полюсов, весов и узлов.

### 11. Нарисовать геометрию в новом 2D-чертеже

Нужны `app`, `owned` и функции `require`, `rectangle`, `line`, `circle`. Код выполняется внутри блока с закрытием своих документов ([§24](documents.md#24-закрыть-только-свои-временные-документы)).

```python
doc = require(app.GetDocuments().AddWithDefaultSettings(c.ksDocumentDrawing, True), "Чертёж")
owned.append(doc)
doc2d = ksapi.IKompasDocument2D(doc)
view = doc2d.GetViewsAndLayersManager().GetViews().GetActiveView()
drawing = ksapi.IDrawingContainer(view)
rectangle(drawing, 50, 50, 100, 60)
line(drawing, (50, 50), (150, 110))
circle(drawing, 100, 80, 10)
```

В чертеже эти функции работают на активном виде; `BeginEdit/EndEdit` 3D-эскиза не нужны. Размеры, листы и оформление в этот рецепт не входят.

### 17. Построить дугу с нужным направлением

Нужен `drawing`. Входные углы удобно считать в **радианах**, в API `SetAngle1/SetAngle2` — **градусы**. `IArc.SetDirection(True)` — по часовой, `False` — против. Центр — `SetXc/SetYc`.

```python
import math

a1, a2 = math.radians(350), math.radians(10)  # размах 20° против часовой
clockwise = False
sweep = ((a1 - a2) if clockwise else (a2 - a1)) % math.tau
obj = require(drawing.GetArcs().Add(), "Дуга")
obj.SetXc(10); obj.SetYc(20); obj.SetRadius(5)
obj.SetAngle1(math.degrees(a1) % 360); obj.SetAngle2(math.degrees(a2) % 360)
obj.SetDirection(clockwise)
require(obj.Update(), "Обновление дуги")
```

Проверяйте длину `radius * sweep` и точки начало/середина/конец на кривой: у малой и дополняющей дуг концы совпадают. Для полной окружности — `GetCircles().Add()`, не одинаковые углы дуги.

### 18. Соединить два участка касательной дугой

#### Готовый случай: два отрезка

Сначала **посчитать** обрезку ломаной и дугу (без вызовов КОМПАС), затем нарисовать отрезки и дугу. Для `(0,0) → (10,0) → (10,10)` и R2: отрезки `(0,0)→(8,0)` и `(10,2)→(10,10)`, дуга с центром `(8,2)`.

Длина обрезки от угла — `radius * tan(abs(turn)/2)`, где `turn` — угол поворота направлений. Не продолжать линии; отвергать радиус, при котором не остаётся двух ненулевых отрезков. В новом эскизе рисуют итоговый контур; при правке старого отдельно заменить исходные отрезки.
#### Произвольные кривые — алгоритм, не готовая функция

Для кривых `A(t)` и `B(u)`:

1. Задайте радиус, стороны сопряжения и разрешённые интервалы. Не продолжайте кривые без требования задачи.
2. Для единичной левой нормали `N=(-dy,dx)/hypot(dx,dy)` решите уравнение `A(t)+side_a*r*N_a(t) = B(u)+side_b*r*N_b(u)`, где стороны равны −1 или +1.
3. Проверьте найденные точки касания, радиус, сторону и допустимые интервалы. Численному решателю недостаточно вернуть `success`; нужна проверка невязки в мм.
4. Обрежьте исходные участки и вставьте дугу с согласованным направлением. Безье делится алгоритмом де Кастельжо, NURBS — корректным разбиением по узлам; простая перестановка конца меняет форму.
5. Проверьте концы, касательные и отсутствие самопересечений. Линейный и угловой допуски задаются отдельно.

Метод требует ненулевых производных; несколько начальных приближений не гарантируют поиск всех решений. Радиус и конструкцию перехода определяет инженерная задача. Например, круговая галтель ножки зуба не равнозначна профилю обкатки.

**Не использовать как готовое сопряжение:** `curve_a.CouplingCurveCurve(curve_b, radius)` существует, но возвращает список чисел, не готовую дугу. Формат списка и обрезка исходных кривых не установлены — не угадывайте индексы и не используйте его как готовое сопряжение.
