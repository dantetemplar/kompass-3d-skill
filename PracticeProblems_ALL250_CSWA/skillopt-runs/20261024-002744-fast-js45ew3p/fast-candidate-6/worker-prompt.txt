# КОМПАС-3D: короткий рабочий маршрут

Цель — правильная нативная модель без лишнего исследования. Полные правила безопасности и параметризации из [reference-SKILL.md](reference-SKILL.md) обязательны. Для необычных операций читать нужный раздел; сигнатуры уточнять адресно через `scripts/sdk.py doc`, при ошибке маршалинга — `inspect`/`page`.

## Выбор маршрута

Существующий документ изменять минимально: параметр → эскиз → операция → вхождение → сопряжение. Искать открытый документ по абсолютному пути, затем при необходимости открывать; проверить тип и путь. Не заменять несохранённое состояние дисковой версией.

Для новой детали из ортогональных профилей скопировать самостоятельный [examples/18_orthogonal_profiles.py](examples/18_orthogonal_profiles.py) в `solution.py`, изменить только `SPEC`. Не импортировать скилл как библиотеку, не переписывать механизм связей. Не повторять импорты, обзоры каталогов и нарезку чертежа без конкретной необходимости.

`SPEC`: `profiles` — список `{plane: XOY|XOZ, vertices:[[u,v],...], circles:[[u,v,r],...], depth:signed}`; `bounds:[xmin,ymin,zmin,xmax,ymax,zmax]`; `volume` — мм³. Один замкнутый ортогональный многоугольник на профиль, без соседних коллинеарных рёбер. Окружности строго внутри, без касаний и пересечений; обе координатные разности центра относительно первой вершины ненулевые. Профили объединяются нативными выдавливаниями; окружности оставляют сквозные пустоты в пределах своего профиля. Маршрут проверен для XOY/XOZ и обоих знаков глубины, не для произвольной топологии. Если условия не подходят, выбрать другой нативный рецепт из справочника.

## Геометрический контракт

До кода кратко зафиксировать размеры, базы, оси, подписанные интервалы материала и признак асимметрии по всем видам. Существенно недостающие размеры блокируют соответствующее построение: не угадывать геометрию; выдать доступный результат и назвать ограничение без запроса уточнений.

В правой системе при фронтальном виде с X вправо и Z вверх положительная Y направлена ОТ наблюдателя, не к нему. От отмеченного начала вывести подписанные интервалы, затем глубины; не выбирать знак по привычному экранному виду.

В указанном рецепте XOY: `(u,v)=(X,Y)`, глубина вдоль Z; XOZ: `(u,v)=(X,-Z)`, глубина вдоль Y. Согласовать ОБЕ настройки: `SetDirection(dtNormal if depth>0 else dtReverse)` и `SetSideParameters(depth>0, etBlind, abs(depth), 0, False, None)`. Не переносить эту семантику на другие операции.

Ожидаемые границы выводить из чертежа, не из первого запуска. При заданных начале и стороне проверка фактических минимумов/максимумов и признака асимметрии ОБЯЗАТЕЛЬНА, даже если общий маршрут допускает проверку только объёма: объём и размеры коробки отражение не исключают. При расхождении диагностировать конкретную настройку, не перебирать знаки и не подгонять ожидания.

## Выполнение и приёмка

Только существующая сессия через `ksapi.GetKompas()`; CAD не запускать и не перезапускать. Один CAD-писатель, без параллельного API-инспектора. Сохранять нативные управляющие размеры и связи; тотальная фиксация не заменяет параметризацию.

Запуск: `bash skill/scripts/run.sh solution.py --output ABS_NEW_PATH`. Не скрывать код завершения конвейером; при конвейере сохранить статус макроса. Проверить ошибки затронутых операций, нужный геометрический признак и заданный объём; без причины не добавлять полный аудит, reopen или тест изменения размеров.

После правки кода или ожиданий заново выполнить итоговый исходник в новый выходной каталог. Выдавать только модель из этого успешного запуска; комментарии и assertions не исправляют прежний артефакт.

Все новые выходы проверять на отсутствие до построения и перед записью; не удалять и не перезаписывать файлы ради обхода диалога. Закрывать только собственные документы, одним владельцем, не более одного раза. При неизвестном исходе нативного вызова прекратить ВСЕ API-вызовы, включая cleanup; сохранить этап и ошибку, не повторять запись вслепую. Кратко сообщить фактический результат и ограничения.
